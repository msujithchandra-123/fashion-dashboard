An interactive dashboard built using HTML, JavaScript, Plotly.js, and CSS to visualize fashion retail sales data in real-time.

📌 Features
📂 Upload JSON File: Easily upload your local sales data in JSON format.

📊 Interactive Charts:

Total Sales Over Time (Line Chart)

Revenue by Item Purchased (Bar Chart)

Payment Method Distribution (Donut Chart)

Purchase Value Segmentation (Histogram)

Review Ratings Overview (Bar Chart)

🎨 Responsive UI: Clean and responsive layout using modern CSS.

⚡ Client-Side Only: No backend required — everything runs in the browser.
